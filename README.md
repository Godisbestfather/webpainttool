# web paint tool

A Chrome extension for drawing and annotating webpages.

## Installation

1. **Download the ZIP file** for Web Paint Tool.

2. **Unzip the downloaded file.**

3. Open Chrome and go to:

   `chrome://extensions`

4. Turn on **Developer mode** in the top-right corner.

5. Click **Load unpacked**.

6. Select the **unzipped Web Paint Tool folder**.

7. The extension should now be installed and ready to use.

> **Note:** You must select the unzipped folder containing `manifest.json`. You cannot select the ZIP file directly.

## Updating

To update Web Paint Tool, download the newest ZIP file, unzip it, and use **Load unpacked** again with the new folder.

## Troubleshooting

If Chrome says **"Manifest file is missing or unreadable"**, make sure you selected the folder that directly contains `manifest.json`.
